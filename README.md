Python Calculator

A simple calculator program built with Python. It uses switch statements to let the user choose and perform different mathematical operations.

Features

Addition

Subtraction

Multiplication

Floor Division

Exponentiation

Modulus

How to Run

Make sure Python is installed on your computer.

Download or clone this project.

Open a terminal in the project folder.

Run:

python calculator.py

Choose an operation and enter the required numbers.

Purpose
This project was created to practice Python basics, including user input, conditional logic, switch statements, and arithmetic operators.
